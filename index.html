3公里 HYROX 體驗關卡說明

HYROX 是目前全球極熱門的「功能性體能競賽」，核心架構為 「跑步/心肺（Cardio Running）+ 功能性體能動作（Functional Fitness Movements）」 的循環交替。

順序 關卡名稱 運動內容與規範 運動科學與體適能目標
暖身 Warm-up 開合跳*30 、深蹲*15、關節活動度伸展、100m 慢跑或漸進加速跑 提升核心體溫、喚醒神經肌肉控制與關節活動度。
01 Run 1 外圈跑道跑 400m * 1 啟動心肺系統，進入預熱狀態。
02 Station 1 Burpee Broad Jump 波比立定跳遠/立定跳遠/ 前進 20 公尺 下肢三關節爆發力與全身無氧代謝。
02 Run 2 外圈跑道跑 200m 考驗波比跳後的「心率控制」與配速。
03 Station 2 Walking Lunges 弓箭步走 30 公尺 股四頭肌與臀大肌離心收縮、單腳穩定度。
03 Run 3 外圈跑道跑 200m 強化乳酸清除速率與心肺耐力。
04 Station 3 Farmers Carry 農夫走負重 30 公尺（雙手提重物）
*雙人合作：手推車 15m 換人或雙人搬運 30m		 核心抗側屈能力、握力與上背肌耐力。
04 Run 4 外圈跑道跑 200m 維持高度代謝率與心率（RPE 15-17）。
05 Station 4 引體向上*30下 或 (懸垂20秒＋高抬腿60秒) 上體水平拉力肌群（背肌/後肩）與高頻率心肺刺激。
05 Run 5 外圈跑道跑 200m 挑戰最大攝氧量（VO2max）極限。
06 Station 5 Thruster / Wall Ball 火箭蹲 20 次 全身性推力與下肢力傳遞至上半身。
06 Run 6 外圈跑道跑 400m * 1 意志力與極限心肺耐力展現。
07 Station 6 Plank Hold + Push-ups 棒式支撐 30秒 + 伏地挺身 10次 = 1組*3 核心穩定度與胸大肌/三頭肌肌耐力。
07 Final Run 最終 200m 衝刺至終點 全力衝刺，完成 HYROX 挑戰！
